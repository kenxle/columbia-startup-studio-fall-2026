# Weekly Update: SettleWise, November 13, 2026

## Accountability: what we did

**Build:** Most of this week went into fixing what last week's usability tests showed:

- **Homepage:** Updated our style guide and redrew the homepage illustrations so visitors understand what SettleWise does. In testing, 3 of 5 users thought it was an apartment marketplace, a saving tool or a bill splitter.
- **Add-listing tutorial:** Made the tutorial for the add-listing button more visual. Every tester struggled to add a listing, and one asked again and again for a video.
- **Step-by-step setup:** Users now set filters and then priorities one page at a time. Testers were confused when everything was on a single "Edit Comparison Fields" screen.
- **Summary text:** Added a written summary and analysis under each comparison. This is the first part of last week's plan to explain why one apartment ranks above another.
- **Display:** Changed how comparison results are shown. For example, boxes are now highlighted when an apartment is over the user's budget. Both testers who "got it" did so from personal signals like going over budget.

Why this differs from the plan: we had planned to focus on the ranking algorithm. Once we reviewed the usability recordings, the confusion in the flow looked like the bigger problem, so the scoring changes are still to come.

**Grow:** Published a blog post page on our website, and posted one reel on Instagram and one on TikTok. We've started posting on Reddit, as our growth plan says, but our posts don't include links to SettleWise yet. So Reddit isn't sending any traffic we can track.

**Analyze:** We didn't do any new analytics work this week because we focused on building. Signups still aren't tracked as a key event in Google Analytics, so we can't measure conversions yet. Setting that up is part of next week's plan.

**Research:** We didn't run any new research sessions this week. All of this week's changes were based on the 5 usability sessions from November 5–6 (see `hw8/user_testing_summary.md`).

## Planning: what we're doing next

**Build:** Fix the ranking algorithm so scores stay consistent when users change priorities or add apartments. This was carried over from last week. Also look at a browser extension as a replacement for the bookmarklet, since the add-listing step blocked all 5 testers.

**Grow:** Start running ad campaigns. Begin adding links to our Reddit posts, using the "paste a listing, see red flags" hook in r/NYCapartments, r/AskNYC and Columbia housing channels. Every link gets a UTM tag so we can tell which channel brings signups.

**Analyze:** Create a Google Analytics key event for signups so we can track users from first visit to a finished signup. Also filter out our own team's traffic, then compare traffic from the ads, Reddit, the reel and the blog by source. Right now we have 0 tracked signups and can't tell which channel any user came from.

**Research:** Run a second round of usability tests with strangers, using a realistic moving-to-NYC scenario and no help from hosts. This will show whether the new homepage, tutorial and step-by-step setup actually work.
