# SettleWise Weekly Update

November 6, 2026

## Accountability: What we built and why

This week, we focused on making SettleWise easier to use. We added automatic rent splitting based on the number of bedrooms and made it possible to see the split rent directly in the comparison table. Users can now delete apartments from the comparison page and remove priorities more easily. We also added an option to add apartments directly from the comparison page, a default price comparison, and a tutorial. We finished the blog and made the bookmarklet button clearer. Most of these changes came from issues we noticed while using and testing the app.

## Planning: What we will build and why

Next week, we want to focus on improving how SettleWise ranks and compares apartments. Right now, the ranking algorithm has some issues with how it scores apartments, especially when users change their priorities or add more apartments. We want to make the rankings more consistent and add feedback that explains why one apartment ranks higher than another. We are also considering using AI to help explain the tradeoffs between apartments. Along with this, we will review our usability testing recordings and decide which other changes are most important.
